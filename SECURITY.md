# Security policy

## Reporting a vulnerability

Please don't report security vulnerabilities in public issues, pull requests or discussions.

Report them privately through GitHub instead:

1. Go to the repository's **Security** tab.
2. Choose **Report a vulnerability**.
3. Say which crate, version or commit is affected, what an attacker can do, and how to reproduce it.

Only the repository's maintainers can see the report. We'll talk it through with you there, agree on a fix and a disclosure date, and credit you in the advisory if you'd like.

## Supported versions

Fixes go into the latest release of each crate, and into `main`.
